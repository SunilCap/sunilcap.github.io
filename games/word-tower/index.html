Each word starts with the last letter of the one before. Stack the tower. Be the last one standing.

How to play

  1. The first word starts with A.
  2. Every next word starts with the last letter of the previous word.
  3. Longer words score more points: one point per letter.
  4. A word that isn’t in the dictionary or has the wrong first letter can be retried before time runs out.
  5. Run out of time and you’re out.
  6. Last player standing wins.

Words are checked against a built-in list, then two online dictionaries. If you’re offline, the game trusts your word.
