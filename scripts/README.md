# Adding or changing a game

## To add a game (2 files, nothing else)
1. Create a folder `games/<name>/` (lowercase, dashes: e.g. `games/sling-puck/`).
2. Put your game in it as `index.html`, and add a small `game.json` next to it (example below).
3. Upload / commit. A GitHub Action runs `scripts/build.py` and, within about a minute, updates:
   home page tile, games list, About page, Privacy list of saved data, Terms (if the game has stars),
   `sitemap.xml`, the offline cache list in `sw.js` (with a fresh version number), and, only if they do not exist,
   the game's `guide.html` and `manifest.webmanifest`.

To remove a game: delete its folder. The next build removes it everywhere.
To change a game's text on the site: edit its `game.json`.
Pages are yours to edit by hand too, except the parts between `<!-- AUTO:... -->` and `<!-- /AUTO:... -->` markers.
If you want to write a guide yourself, upload `games/<name>/guide.html` (without the "generated by build" first line).

## game.json
```json
{
  "title": "Sling Puck",
  "emoji": "🥏",
  "order": 60,
  "tagline": "Pull back, aim, and let it fly.",
  "description": "Drag back to sling the puck across the table and knock your targets off the edge.",
  "bestFor": "aiming, planning shots, and quick rounds.",
  "controls": "drag back and release, or use the mouse on a computer.",
  "saves": "your best score",
  "sound": true,
  "stars": false,
  "share": false
}
```
* `title`, `description` are required. `order` sets the position (small numbers first).
* `saves`: what the game stores in the browser, finishing "saves ..." (this becomes the Privacy list). Use `null` if it stores nothing.
* `stars`: true if it has collectible stars (adds it to the Terms sentence). `share`: true if it has a Share button. `sound`: true if it has a sound control.
* Optional text overrides: `tileHead`, `tileBody`, `short`, `about`, `glance`, `controlsLabel`, `guideLabel`, and a `guide` object
  (`goal`, `controls` [[action, touch, keyboard]], `tips` [..], `faq` [[question, answer]]) used when the guide page is generated.
* Optional icons: `icons/<name>-192.png` and `icons/<name>-512.png` (used in the manifest and offline cache).

## Every game's index.html should contain (the build prints a warning if not)
the Google ads script + `adBreak`/`adConfig` hook, the Scotcha badge, a viewport meta tag,
`<link rel="manifest" href="/games/<name>/manifest.webmanifest">`, and the service-worker registration line.
Copy these from `games/hold-up/index.html`.

## One-time GitHub setup
Settings -> Actions -> General -> Workflow permissions -> "Read and write permissions" -> Save.
Check runs under the Actions tab ("Build site"). Local run: `python3 scripts/build.py`.
